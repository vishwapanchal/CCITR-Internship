# Sample APK Files for Testing

These APK files are pre-packaged for quick testing with APEX-X. Upload any of them through the web interface to see the full analysis pipeline in action.

| App | Description | Source |
|-----|-------------|--------|
| `AndroGoat.apk` | OWASP intentionally vulnerable Android app for security testing | [GitHub](https://github.com/satishpatnayak/AndroGoat) |
| `DivaApplication.apk` | Damn Insecure and Vulnerable App — teaches common Android vulnerabilities | [GitHub](https://github.com/0xArab/diva-apk-file) |
| `InsecureShop.apk` | Intentionally vulnerable shopping app covering OWASP Mobile Top 10 | [GitHub](https://github.com/hax0rgb/InsecureShop) |

> **Note:** These apps are intentionally vulnerable and designed for educational security testing. Do not install them on personal devices.
